# Site Plan Wireframe

Overview
- Simple site wireframe outlining the main sections and visual choices.

Pages / Sections
- Home
  - Introduction / tagline
  - Featured projects (highlight 1–3)
  - Key skills / short summary
- Projects / Work
  - Three project placeholders (title, short description, link, image)
- About / Contact
  - Short bio
  - Detailed skills list
  - Contact information / form or mailto link

Visuals
- Color palette: Navy blue, light blue, gray, white
- Fonts: Arial or Helvetica (for headings and body)

Notes
- Keep layout responsive: stack content on small screens, two/three columns on larger screens.
- Use project cards with image, title, short blurb, and link.
- CTA on Home to view Projects and Contact.
